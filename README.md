# # 🌫️ Real-Time AQI Dashboard

This is a simple, interactive dashboard built with **Streamlit** that fetches and displays real-time **Air Quality Index (AQI)** data for selected Indian cities using the **AQICN (World Air Quality Index)** API.

---

## 🔧 Features

- Select any city from the dropdown menu
- Fetch current AQI value instantly
- Displays:
  - City name
  - AQI value
  - Dominant pollutant
  - Last updated time
- Minimal design with responsive layout

---

## 📦 Requirements

- Python 3.7+
- Streamlit
- Requests
